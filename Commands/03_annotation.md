# 🧬 Genomic Annotation Guide

This step-by-step guide shows how to annotate chloroplast and mitochondrial genomes using online tools. The entire workflow is web-based, **with no command-line required**.

---

## 📍 Step 1: GeSeq Annotator

**GeSeq** is an excellent tool used for annotating chloroplast and mitochondrial genomes.

[![Access GeSeq](https://shields.io)](https://mpg.de)

### 📋 How to use:
1. Open the GeSeq website.
2. Upload your genomic file in `.fasta` format.
3. Select a closely related species from the database if available.
4. Run the annotation.

---

## 📍 Step 2: Mitofy Server

**Mitofy** is specifically designed for annotating plant mitochondrial genomes.

[![Access Mitofy](https://shields.io)](https://wisc.edu)

### 📋 How to use:
1. Upload your `.fasta` file to the server.
2. Wait for the program to process and display the results.

---

## 📍 Step 3: Manual Curation with GenomeView

After running the automatic annotators, use **GenomeView** to manually check and refine your data.

[![Access GenomeView](https://shields.io)](https://genomeview.org)

### 📋 How to use:
1. Load your output files into the software.
2. Inspect the gene boundaries and make corrections where needed.
